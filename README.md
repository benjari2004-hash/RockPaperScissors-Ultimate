# RockPaperScissors-Ultimate

A Java Swing-based advanced Rock Paper Scissors game.

## Features

- Player vs Player (PvP)
- Player vs Computer (PvC)
- AI prediction strategy
- Best-of-three tournament system
- Animated user interface
- Sound effects
- Anti-cheating detection
- Keyboard controls

## Technologies

- Java
- Java Swing
- Object-Oriented Programming
- Event-driven design

## Controls

### PvP Mode

Player 1:
- A = Rock
- S = Paper
- D = Scissors

Player 2:
- J = Rock
- K = Paper
- L = Scissors

### PvC Mode

- Space = Rock
- B = Paper
- N = Scissors

Compile:

```bash
javac RockPaperScissorsGame.java
