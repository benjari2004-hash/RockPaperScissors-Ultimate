# RockPaperScissors-Ultimate 🎮

A Java Swing-based advanced Rock Paper Scissors game with multiple game modes, AI strategy, animations, and an interactive graphical user interface.

## 📌 Project Overview

RockPaperScissors-Ultimate is a desktop game developed using Java Swing.  
The project extends the traditional Rock Paper Scissors game by adding Player vs Player mode, Player vs Computer mode, AI prediction strategy, animations, sound effects, and tournament gameplay.

The project demonstrates concepts of:
- Object-Oriented Programming (OOP)
- Event-driven programming
- GUI development using Java Swing
- Game logic design
- AI-based decision making

---

# ✨ Features

## 🎮 Game Modes

### Player vs Player (PvP)
- Two players can compete on the same computer.
- Each player has independent controls.
- Real-time winner calculation.

### Player vs Computer (PvC)
- Play against an AI-controlled opponent.
- Computer uses prediction strategy to improve gameplay.
- Dynamic decision making.

# ▶️ How to Run

## Requirements

- Java JDK installed (Java 17 or higher recommended)

Check Java version:

```bash
java -version
```

---

## Compile

```bash
javac RockPaperScissorsGame.java
```

---

## Run

```bash
java RockPaperScissorsGame
```
